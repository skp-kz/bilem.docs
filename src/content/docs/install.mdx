## Что нужно

- **Windows** 10 или 11, Windows Server 2012 R2 или новее; .NET Framework 4.8.
- **1С:Предприятие 8.3** на этом же компьютере и база **«1С:Бухгалтерия для Казахстана»**, редакция 3.0. Пока — файловая база; клиент-серверные — в следующих версиях.
- **Права администратора Windows** — на время установки.
- **Логин и пароль администратора 1С** — один раз при подключении базы. Не сохраняются.

IIS (веб-сервер Windows) нужен для стандартного интерфейса 1С; если его нет, агент включит его сам.

## Подключение базы

<Steps>

1. **Установите Bilem Agent** и запустите. Значок появится в трее.

2. **Базы 1С → Добавить.** Агент сам находит базы из списка 1С на этом компьютере — выберите нужную.

3. **Введите логин и пароль администратора 1С.** Агент покажет план — что создаст и что включит — и после вашего «Применить» сделает всё сам.

4. **Проверка.** Агент убеждается, что под пользователем `bilem` база читается, а запись запрещена, и показывает «Запись запрещена — проверено».

5. **Подключите ИИ.** Вкладка **MCP** → «Скопировать» адрес → [Подключение агентов](/connect/).

</Steps>

## Что агент меняет

| Где | Что |
|---|---|
| База 1С | пользователь `bilem` с типовыми ролями только на чтение; состав стандартного интерфейса OData — только нужные объекты (без зарплаты и кадров) |
| IIS | публикация базы, доступная **только с этого компьютера** (127.0.0.1); отдельный пул на каждую базу |
| Компьютер | папка настроек `C:\ProgramData\Bilem` (доступ — только администраторы); документы — в `Документы\Bilem\<база>\` |

Конфигурацию 1С агент не меняет и расширений не ставит — обновления 1С ставятся как обычно.

## Несколько баз

Добавьте каждую базу отдельно: у каждой свой пользователь `bilem`, своя публикация и свои печатные формы. В бесплатной версии число баз не ограничено.
