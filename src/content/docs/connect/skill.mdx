MCP даёт агенту **инструменты**, а скилл — **навык**: короткую инструкцию, как ими пользоваться. С ним агент в любой программе:

- берёт цифры только из 1С и не досчитывает «примерно»;
- называет, на какую дату данные;
- перед отправкой документа предлагает показать его вам;
- не трогает учёт и не уходит в посторонние темы.

Скилл — обычный текстовый файл `SKILL.md`. Бесплатно для всех.

<LinkButton href="/skills/bilem/SKILL.md" icon="download" download="SKILL.md">Скачать SKILL.md</LinkButton>

## Установка

Скилл — это папка `bilem` с файлом `SKILL.md` внутри.

| Программа | Куда положить |
|---|---|
| Claude Code | `~/.claude/skills/bilem/SKILL.md` |
| OpenClaw, Hermes и другие агенты со скиллами | папка `bilem` в папке скиллов агента, затем перезапуск |
| Claude Desktop и claude.ai | Settings → Capabilities → Skills → загрузить архив [bilem.zip](/skills/bilem.zip) (та же папка с тем же файлом) |
| Программы без скиллов | вставьте текст `SKILL.md` в системную инструкцию агента |

Скилл обновляется вместе с агентом: когда появляются новые инструменты, скачайте файл заново.
