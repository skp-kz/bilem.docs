import { Steps } from '@astrojs/starlight/components';

Bilem Agent принимает подключения только с того компьютера, где установлен (`127.0.0.1`), — так ваша 1С не видна ни в сети, ни в интернете. Если ИИ работает на другом компьютере — ноутбуке, Mac, сервере с OpenClaw, — проще всего открыть агент внутри своей частной сети [Tailscale](https://tailscale.com). Для небольшой компании это бесплатно.

<Steps>

1. **Установите Tailscale** на компьютер с Bilem Agent и на компьютер с ИИ, войдите в одну и ту же сеть.

2. **На компьютере с Bilem Agent** выполните в командной строке:

   ```sh
   tailscale serve --bg --https=8796 http://127.0.0.1:8796
   ```

3. **Узнайте новый адрес:** `tailscale serve status`. Он вида `https://<имя-компьютера>.<ваша-сеть>…:8796`.

4. **Добавьте к нему путь с ключом** из Bilem Agent — ту же часть `/mcp/…` — и подключайте ИИ [как обычно](/connect/), только с этим адресом.

</Steps>

Адрес доступен только устройствам вашей сети Tailscale; из интернета его не видно. Bilem Agent запишет в журнал, какой пользователь сети обращался.

## Кому открыть

По умолчанию в сети Tailscale все устройства видят друг друга. Чтобы агент был доступен только нужным компьютерам, ограничьте порт `8796` правилами доступа (Access controls) в консоли Tailscale.

## Выключить

```sh
tailscale serve --https=8796 off
```

:::tip[Открытый код]
Нужен другой способ — nginx, Caddy, свой прокси? Код Bilem Agent открыт: публикуйте так, как принято у вас.
:::
