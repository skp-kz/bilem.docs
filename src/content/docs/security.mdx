## Только чтение

Расширение `bilem.cfe` читает базу и не меняет учёт: не проводит документы, не создаёт платёжки, не правит справочники. Таких действий в коде нет.

## Права — в вашей 1С

Bilem работает под отдельным пользователем 1С с ролями расширения. Какие разделы ему доступны, решает администратор вашей базы — в обычном пользовательском режиме, без доработки конфигурации. Отключённый раздел агент просто не видит.

## Что уходит в модель, а что нет

- **Уходит:** ваш вопрос и ответ 1С на этот вопрос — суммы, названия контрагентов, даты, которые нужны для ответа.
- **Не уходит:** база целиком, пароли, ключи, данные, о которых вы не спрашивали.
- **Зарплата:** только суммы, без фамилий и ИИН — даже если попросить.

## Где хранятся данные

- База 1С остаётся у вас: облако Bilem её не копирует и не хранит.
- Контекст беседы хранится ограниченное время, затем удаляется.
- Постоянная память — только то, что вы сами попросили запомнить; её можно посмотреть и удалить в кабинете.
- Связь с 1С — одно исходящее зашифрованное соединение от вашей службы; входящие порты открывать не нужно.

## Запись — в будущем и только с подтверждением

Когда появятся документы, меняющие базу (счёт, акт, новый контрагент), каждое действие пройдёт четыре шага:

1. **Проба** — действие выполняется с откатом, чтобы поймать ошибки; в базе ничего не остаётся.
2. **Показ** — вы видите, что будет создано.
3. **Ваше «да»** — без явного подтверждения ничего не записывается.
4. **Проверка по факту** — «готово» агент скажет, только перечитав базу и убедившись, что документ есть и сумма совпадает.
