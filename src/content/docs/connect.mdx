**Bilem Agent** — программа для Windows рядом с вашей 1С. Она читает базу и работает как MCP-сервер, а MCP понимает любой современный ИИ: чат-приложения, редакторы кода, агенты, локальные модели. Это бесплатно и с открытым кодом.

<Steps>

1. **Скопируйте адрес.** Bilem Agent → вкладка **MCP** → «Скопировать». Адрес вида `http://127.0.0.1:8796/mcp/…` — в нём секретный ключ доступа.

2. **Добавьте в свою программу.** Выберите её ниже и повторите шаги — обычно это одна команда или пара строк в настройках.

3. **Проверьте.** Спросите ИИ: «вызови bilem whoami» — он ответит, какие базы 1С видит.

</Steps>

## Скилл Bilem — бесплатно для всех

MCP даёт агенту инструменты, а скилл — навык: короткую инструкцию, как ими пользоваться. Всегда называть дату данных, не выдумывать цифры, отправлять документы только после вашего подтверждения, не трогать учёт. С ним агент отвечает одинаково аккуратно в любой программе. Это обычный текстовый файл `SKILL.md`.

<LinkButton href="/skills/bilem/SKILL.md" icon="download" download="SKILL.md">Скачать SKILL.md</LinkButton>

Скилл — это папка `bilem` с этим файлом внутри.

- **Claude Code** — положите файл в `~/.claude/skills/bilem/SKILL.md`.
- **OpenClaw, Hermes и другие агенты со скиллами** — создайте в папке скиллов агента папку `bilem`, положите в неё `SKILL.md` и перезапустите агента.
- **Claude Desktop и claude.ai** — Settings → Capabilities → Skills: загрузка принимает архив, поэтому для них есть готовый [bilem.zip](/skills/bilem.zip) — та же папка с тем же файлом.
- **Агенты без скиллов** — вставьте текст `SKILL.md` в системную инструкцию.

## Программа на другом компьютере

Bilem Agent принимает подключения только с того компьютера, где установлен (`127.0.0.1`), — так ваша 1С не видна в сети. Если ИИ работает на другом компьютере, опубликуйте адрес внутри своей частной сети [Tailscale](https://tailscale.com): установите Tailscale на оба компьютера и на компьютере с агентом выполните

```sh
tailscale serve --bg --https=8796 http://127.0.0.1:8796
```

Новый адрес покажет команда `tailscale serve status`; к нему добавьте ту же часть `/mcp/…` с ключом. Адрес доступен только устройствам вашей сети Tailscale, из интернета его не видно.

:::tip[Открытый код]
Нужен другой способ публикации — nginx, Caddy, свой прокси? Код Bilem Agent открыт: дорабатывайте под себя.
:::

## Безопасность

- Адрес с ключом — это доступ к данным вашей 1С. Не пересылайте его и не публикуйте.
- Адрес попал к чужим — Bilem Agent → **MCP** → «Сменить токен…». Старый адрес перестаёт работать сразу, во всех программах.
- Bilem не меняет учёт: читает данные и готовит только счета, доверенности, акты сверки и карточки контрагентов — после вашего подтверждения. Подробнее — [Безопасность](/security/).

## Частые вопросы

<details>
<summary>Почему ChatGPT, Claude на телефоне и мессенджеры — платно?</summary>

Они работают в интернете и не видят ваш компьютер. Им нужен постоянный защищённый адрес, вход по учётной записи и сервер, который работает круглосуточно, — это Bilem Cloud, коммерческая версия. Всё, что работает на вашем компьютере, — бесплатно. См. [Тарифы](/pricing/).

</details>

<details>
<summary>Моей программы нет в списке</summary>

Если она умеет MCP по HTTP (Streamable HTTP) — подключайте по образцу «Другая программа». Напишите нам на [GitHub](https://github.com/skp-kz/bilem.ai/issues) — добавим инструкцию.

</details>

<details>
<summary>ИИ не видит инструменты bilem</summary>

Проверьте, что Bilem Agent запущен (в трее зелёный значок, на вкладке **MCP** — «Работает»), адрес скопирован целиком, а программа перезапущена после изменения настроек.

</details>
