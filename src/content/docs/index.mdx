**Bilem** (білем — «знаю» по-казахски) — агент для вашей 1С. Вы спрашиваете ИИ обычными словами — он отвечает цифрами из вашей базы, готовит документы и отправляет их по почте:

- «Сколько у нас денег?» — остатки на банковских счетах и в кассе.
- «Найди „Альфу“» — контрагент по названию или БИН.
- «Дай счёт № 4 „Альфе“ и отправь им на почту» — счёт на оплату в PDF с логотипом, печатью и подписью; перед отправкой ИИ предложит показать его в чате.

Скоро: доверенность и акт сверки, должники и кредиторы, продажи, налоги. Полный список — [Инструменты](/tools/).

## Две версии

| | **Bilem Agent** — бесплатно | **Bilem Cloud** — по подписке |
|---|---|---|
| Где работает | на вашем компьютере или сервере рядом с 1С | агент у вас + облако Bilem |
| С какими ИИ | Claude Desktop и Claude Code, Cursor, VS Code, Codex, OpenClaw, Hermes, локальные модели — всё, что умеет MCP | плюс ChatGPT, Claude на телефоне, WhatsApp, Telegram |
| Модель ИИ | ваша (свой ключ или локальная) | включена в подписку |
| Базы 1С | любое число | по тарифу |
| Код | открытый | — |

## Как это устроено

1. **Bilem Agent** — программа для Windows. Её ставят на компьютер или сервер, где работает 1С.
2. При настройке вы один раз вводите пароль администратора 1С. Агент создаёт в базе пользователя `bilem` только с правами на чтение и включает стандартный интерфейс 1С (OData) — **только для этого компьютера**. Пароль администратора не сохраняется.
3. Агент — **MCP-сервер**: ваш ИИ подключается к нему по адресу с секретным ключом и получает инструменты — «деньги», «контрагент», «счёт» и другие.
4. ИИ вызывает инструмент — агент читает 1С и отдаёт ответ или готовый PDF.
5. В Bilem Cloud агент сам соединяется с облаком исходящим соединением: публиковать базу в интернет и открывать порты не нужно.

## Главные принципы

- **Учёт не меняем.** Bilem не проводит и не удаляет документы, не правит проводки.
- **Запись — только белый список.** Создавать Bilem может лишь счета, доверенности, акты сверки и карточки контрагентов — непроведёнными.
- **Без доработки 1С.** Ни расширений, ни изменений конфигурации: обновления 1С ставятся как обычно.
- **База остаётся у вас.** Данные 1С не копируются в облако — проходят только вопрос и ответ.
- **Честные цифры.** Нет данных — агент так и скажет, а не придумает.
- **Открытый код.** Что делает агент, может прочитать любой программист.
