## С какими конфигурациями 1С работает Bilem?

Сейчас — «1С:Бухгалтерия для Казахстана», редакция 3.0. Другие конфигурации — по мере готовности.

## Нужен ли программист?

Для установки — нет: установщик, выбор базы и один раз пароль администратора 1С. Остальное агент сделает сам — см. [Установка](/install/). Подключить свой ИИ поможет [пошаговая инструкция](/connect/) для каждой программы.

## База файловая — подойдёт?

Да. Сейчас Bilem Agent подключает **файловые** базы; клиент-серверные — в следующих версиях. Агент ставится на компьютер, где установлена платформа 1С и лежит база.

## Что будет при обновлении 1С?

Ничего особенного: Bilem не ставит расширений и не меняет конфигурацию, поэтому обновления 1С устанавливаются как обычно.

## Чем бесплатная версия отличается от платной?

**Bilem Agent** — бесплатно и с открытым кодом: работает на вашем компьютере, подключается к вашему ИИ (Claude, Cursor, OpenClaw и другим), любое число баз. **Bilem Cloud** — по подписке: ChatGPT, Claude на телефоне, WhatsApp и Telegram, модель ИИ включена, поддержка. См. [Тарифы](/pricing/).

## Нужен ли интернет?

Самому агенту — нет, он работает рядом с 1С. Интернет нужен вашему ИИ, если модель облачная; с локальной моделью всё работает без него.

## Чем Bilem отличается от коннектора к 1С «своими руками»?

Коннектор даёт модели доступ к данным — дальше всё на вас: публикация, права, безопасность. Bilem Agent делает это за вас: отдельный пользователь только для чтения, доступ только с этого компьютера, проверка прав, печать документов с печатью и подписью, отправка по почте (доверенности — только на ваши адреса), журнал. И это тоже бесплатно.

## Где получить помощь?

- **Бесплатно — через GitHub.** Вопросы по установке и настройке — в [Обсуждениях](https://github.com/skp-kz/bilem.ai/discussions/categories/q-a), ошибки — в [Issues](https://github.com/skp-kz/bilem.ai/issues/new/choose). Приложите отчёт для поддержки (Bilem Agent → вкладка «Журнал»): паролей, токенов и данных 1С в нём нет. Отвечаем в порядке очереди, когда есть время, — без сроков и гарантий: Bilem Agent распространяется с открытым кодом «как есть» (лицензия MIT).
- **Адресная поддержка — по подписке Bilem Cloud.** Отвечаем лично и в оговорённый срок, помогаем с установкой и подключением баз, разбираем проблемы на вашем сервере. Обращение — в кабинете [app.bilem.ai](https://app.bilem.ai).
- **Уязвимость** — не в публичный issue: [сообщить приватно](https://github.com/skp-kz/bilem.ai/security/advisories/new).
